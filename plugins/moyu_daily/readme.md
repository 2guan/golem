# 打工人摸鱼办日报插件 (moyu_daily)

专为职场打工人打造的摸鱼办温馨日历助手：精准测算距离周末、发工资日、下一个法定节假日的倒计时天数，并附赠每日防内卷清醒箴言。

---

## 📌 核心功能

1. **精准节假日倒计时**：
   - 自动根据当前日期实时计算距离本周五下班、本周末的倒计天数。
   - 智能识别距离每个月 10 号 / 15 号发薪日的剩余天数。
   - 自动感知中国法定节假日（元旦、春节、清明、五一、端午、中秋、国庆）的倒计时。
2. **防内卷摸鱼箴言**：
   - 内置上百条幽默生动、接地气的防内卷清醒金句，慰藉打工人疲惫灵魂。
3. **工作日定时打卡推送**：
   - 支持配置工作日每周一至周五上午 10:00 自动定时推送摸鱼日历到指定微信群。
4. **手动即时调阅**：
   - 群聊或私聊中随时发送关键词即可即刻触发。

---

## 🎮 使用方法与触发词

| 指令 | 说明 |
| :--- | :--- |
| `摸鱼办` / `摸鱼日报` | 生成并发送当天的完整打工人摸鱼办日报 |
| `摸鱼日历` / `摸鱼倒计时` | 同上，别名指令 |
| `今日摸鱼` / `摸鱼` | 同上，别名指令 |
| `摸鱼帮助` / `摸鱼办帮助` | 查看插件功能说明 |

---

## ⚙️ 配置说明

在 `plugins/config.toml` 中配置：

```toml
[moyu_daily]
enable = true
mode = 'blacklist'
limits = []

[moyu_daily.config]
# 配置工作日 10:00 自动推送的目标群聊 ID 列表（留空表示不自动推送，仅支持手动指令触发）
auto_push_chatrooms = [
  # "123456789@chatroom",
]
```
