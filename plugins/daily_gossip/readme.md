# 每日群聊八卦小报插件 (daily_gossip)

自动监听提炼群内消息历史，在每天固定时间自动排版推送当天的“群聊吃瓜晚报”，也支持群成员随时发送指令即时获取今日专属八卦战报。

---

## 📌 核心功能

1. **自动提炼群话题**：跟踪记录群内一整天的聊天发言、热烈讨论的高频词和焦点事件。
2. **水群榜与龙王盘点**：统计当日发言最活跃的“水群龙王”与话题制造机。
3. **金句捕捉与神评盘点**：摘录当日群友最具喜剧效果或调侃意义的趣味言论。
4. **定时自动晚报**：每天 22:00 自动为全天有活跃发言的微信群生成排版精致的吃瓜小报。
5. **手动即时生成**：群聊成员可随时发送指令即时调阅当前时刻的八卦日报汇总。

---

## 🎮 使用方法与触发词

| 指令 | 说明 |
| :--- | :--- |
| `今日八卦` / `群八卦` | 即时生成并查看本群从早到现在的八卦吃瓜小报 |
| `吃瓜日报` / `八卦日报` | 同上，别名指令 |
| `吃瓜晚报` / `群报` | 同上，别名指令 |
| `八卦帮助` / `吃瓜帮助` | 查看本插件指令用法指南 |

---

## ⚙️ 配置说明

在 `plugins/config.toml` 中配置：

```toml
[daily_gossip]
enable = true
mode = 'blacklist'
limits = [] # 可在此配置限制生效的群聊列表
```
