# 谁是卧底聚会桌游插件 (undercover)

经典文字派对桌游《谁是卧底》裁判系统：全自动完成群内成员报名、私聊分发身份词语、主持轮流发言轮次、投票放逐结算以及平票决胜。

---

## 📌 核心功能

1. **自动报名集结**：群内一键发起，群友直接发送 `+1` 或 `报名` 即可加入（支持 3~8 人）。
2. **私聊保密发词**：游戏开始后，机器人自动通过私聊将平民词与卧底词分别发送给每位玩家。
3. **轮流发言主持**：群内自动编排座位号，提醒玩家按顺序发言描述手中词语。
4. **投票统计与处决放逐**：支持指定投票指令（如 `投1号`），自动计票并公布得票结果与淘汰玩家。
5. **胜负裁判**：当所有卧底被放逐（平民获胜）或卧底人数达到存活半数（卧底获胜）时，自动结算并公布所有玩家底牌。

---

## 🎮 使用方法与流程

| 阶段 | 指令 | 说明 |
| :--- | :--- | :--- |
| **发起招募** | `发起谁是卧底` / `谁是卧底` | 在群内发起新一局招募（创建房间） |
| **群友加入** | `+1` / `报名` / `加入` | 群友在群内发送即可成功上车 |
| **开始游戏** | `开始游戏` / `开始谁是卧底` | 发起人确认人数（3~8人）后开启，机器人私聊分发词语 |
| **投票放逐** | `进入投票` / `开始投票` | 发言结束后开启投票环节 |
| **玩家投票** | `投1号` / `投X号` | 存活玩家投票处决怀疑目标 |
| **计票结算** | `公布票数` / `结算投票` | 统计全员票数并宣布放逐结果 |
| **提前结束** | `结束谁是卧底` / `重置谁是卧底` | 随时重置群内房间状态 |
| **查阅指南** | `谁是卧底帮助` | 查看本游戏完整规则说明 |

---

## ⚙️ 配置说明

在 `plugins/config.toml` 中配置：

```toml
[undercover]
enable = true
mode = 'blacklist'
limits = []
```
