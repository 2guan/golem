# Golem Web 管理控制台 (dashboard)

一站式可视化 Web 管理后台，提供参数配置管理、插件中心、单人专属人设策略、全模态聊天记录审计与独立运行日志诊断中心。

---

## 📌 核心功能

1. **系统运行概览**：查看微信登录状态、运行时间、已加载插件数与全局通讯录概览。
2. **插件管理中心**：
   - 查阅所有已安装官方与自定义插件的完整中文使用指南、触发词与示例。
   - 一键启用/禁用插件，支持黑白名单目标过滤。
   - 可视化编辑 TOML 专属参数并热重载生效。
3. **AI 专属人设与策略**：
   - 支持为指定私聊好友或群聊定制独立的系统提示词（System Prompt）。
   - 为单目标设置专属称呼、专属回复概率（Reply Rate）与静默开关。
4. **实时对话与模拟管理**：
   - 管理员可在 Web 后台直接以当前微信号身份与联系人/群聊实时互发文本、图片、语音。
   - 自动与本地 AI 上下文记忆同步。
5. **系统日志诊断检索**：
   - 实时跟踪 Golem 核心与各插件的 stdout/stderr 运行日志。
   - 支持按日志级别（INFO, WARN, ERROR）与关键字进行高速检索。

---

## 🌐 访问地址与登录

- **默认访问端口**：`http://127.0.0.1:8899`
- **默认管理员账号**：`admin`
- **默认管理员密码**：`admin123`

> 建议在初次登录后，前往后台页面右上角或安全模块修改高强度密码。

---

## ⚙️ 配置说明

在 `plugins/config.toml` 中配置：

```toml
[dashboard]
enable = true
mode = 'blacklist'
limits = []

[dashboard.config]
host = '0.0.0.0'   # 监听地址（0.0.0.0 允许局域网访问，127.0.0.1 仅限本机）
port = 8899        # Web 服务监听端口
data_dir = 'data'  # 会话历史与媒体缓存数据存储目录
```
