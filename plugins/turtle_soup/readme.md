# 海龟汤推理派对插件 (turtle_soup)

经典情境推理桌游（海龟汤）：机器人化身专业主持人，既支持本地经典名案题库，也支持大模型现场现场定制全新好汤。主持玩家自由提问并判定，提供渐进线索直到破案揭底。

---

## 📌 核心功能

1. **双模式汤底供给**：
   - 🍲 **AI 现场熬汤**：调用大模型即时生成未曾面世的全新原创好汤，支持指定主题（温馨感人、烧脑诡异、职场反转等）。
   - 📚 **经典名案题库**：内置多道经典海龟汤题库，保障无外部网络时也能秒级开局。
2. **智能裁判与提问判定**：
   - 玩家在群内自由提问（如：“死者是在白天死的吗？”、“现场有第三个人吗？”）。
   - AI 主持人精准判定：【是】/【不是】/【与此无关】/【关键线索！】。
3. **关键线索渐进提示**：
   - 推理陷入僵局时，玩家可请求线索提示，主持人按梯度释放破案钥匙。
4. **破案侦破与完整揭底**：
   - 玩家猜中核心反转时自动宣布【破案了！】；也可主动放弃查看完整真相还原。

---

## 🎮 使用方法与触发词

| 指令 | 说明 |
| :--- | :--- |
| `来碗海龟汤` / `开局海龟汤` / `海龟汤` | 开启一轮新游戏（默认由 AI 现场生成新题目） |
| `经典海龟汤` / `题库海龟汤` | 强制从本地经典名案题库中随机抽取开局 |
| `私房海龟汤 [主题]` / `AI海龟汤 [主题]` | 定制特定题材海龟汤（如：`私房海龟汤 职场复仇`） |
| `[自由提问句子]` | 在游戏中直接发问（如：死者认识凶手吗？），AI 主持人自动研判 |
| `海龟汤提示` / `要提示` | 推理卡壳时获取一条渐进破案线索 |
| `看汤底` / `放弃海龟汤` / `揭晓汤底` | 放弃推理，提前揭晓全部真相与案件全貌 |
| `海龟汤帮助` | 查看海龟汤规则与指令指南 |

---

## ⚙️ 配置说明

在 `plugins/config.toml` 中配置：

```toml
[turtle_soup]
enable = true
mode = 'blacklist'
limits = []
```
