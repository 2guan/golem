# 伪造聊天记录与合并转发插件 (fake_forward)

支持手动自定义成员名字与对话内容，生成高度逼真的微信聊天记录合并转发卡片，用于段子创作、情景模拟或趣味剧情互动。

---

## 📌 核心功能

1. **多角色剧本构建**：通过简单的命令行格式，自由组装多位成员的聊天对话气泡。
2. **群成员智能头像关联**：在群聊中生成时，若角色名字与本群成员昵称匹配，将自动抓取该成员的真实微信头像与昵称作为气泡发送者。
3. **支持指定转发目标**：支持将伪造好的合并转发卡片直接推送到当前会话，或通过参数指定推送至特定群聊。

---

## 🎮 使用方法与命令格式

使用标准命令 `/fake`：

```bash
/fake [-c 群聊名称] 名字1:内容1|名字2:内容2|...
```

### 交互示例

1. **基础双人对话**：
   ```text
   /fake 小明:今晚去吃火锅吗？|小红:好呀，几点去？|小明:七点校门口集合！
   ```
2. **在群内生成群友互怼记录**（名字会自动匹配当前群成员并提取真实头像）：
   ```text
   /fake 张三:今天又加班了...|李四:快跑，下班不积极思想有问题！
   ```
3. **指定推送到特定群聊**：
   ```text
   /fake -c 摸鱼划水群 组长:大家这周辛苦了，明天全体放假！
   ```

---

## ⚙️ 配置说明

在 `plugins/config.toml` 中配置：

```toml
[fake_forward]
enable = true
mode = 'blacklist'
limits = []
```
