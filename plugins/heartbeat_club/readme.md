# 心跳沉浸馆插件 (heartbeat_club)

集三大经典荷尔蒙场景于一体的双端文字互动 RPG：支持**私聊 1V1 沉浸剧场**（电影级文字剧情互动）与**群聊荷尔蒙大乱斗**（力量比拼、微醺大冒险与查寝破冰玩法）。

---

## 📌 核心功能与场景设计

### 1. 私聊 1V1 深度沉浸剧场
- 🏋️ **场景一：铁馆更衣室 (Locker Room)** —— 杠铃轰鸣、蒸汽弥漫、汗水与紧绷肌肉线条的直球张力。
- 🍸 **场景二：微醺小酒馆 (Tavern & Bar)** —— 昏暗爵士、加冰威士忌、成熟调酒师与成年人的眼神试探。
- 🎽 **场景三：男生宿舍熄灯后 (Dorm After Lights Out)** —— 闷热夏夜、风扇转动、上下铺翻身声与被窝里的低语。

私聊进入沉浸场景后，机器人的回复将完全融入该场景氛围，输入自由动作或对话推进剧情，直至主动发送“退出”。

### 2. 群聊荷尔蒙大乱斗（即玩即结）
无需进入等待模式，群成员随时触发互动，活跃气氛：
- 🏋️‍♂️ **力量对抗**：掰手腕对决、身材对比打分。
- 🍸 **微醺大冒险**：酒吧随机真心话、大冒险或酒局惩罚。
- 🎽 **突袭查寝**：查看当前寝室状态与群员荷尔蒙纪要。
- 💘 **张力契合度**：测算两名群友之间的荷尔蒙契合指数。

---

## 🎮 使用方法与触发词

### 群聊互动指令
| 指令 | 说明 |
| :--- | :--- |
| `心跳沉浸馆` / `心跳俱乐部` / `心跳帮助` | 查看心跳馆玩法菜单 |
| `@某人 掰手腕` | 发起与指定群友的力量角逐对决 |
| `@某人 比拼身材` / `身材比拼` | 两人体态力量大对比 |
| `微醺大冒险` / `酒吧摇骰` | 随机摇骰抽取微醺大冒险惩罚 |
| `宿管查寝` / `突袭查寝` | 生成宿舍荷尔蒙查寝报告 |
| `契合度 @某人` | 测算两人之间的张力契合度指数 |

### 私聊沉浸剧场指令
| 指令 | 说明 |
| :--- | :--- |
| `心跳沉浸馆` / `心跳俱乐部` | 唤醒剧场选择菜单（铁馆 / 酒吧 / 宿舍） |
| `铁馆更衣室` / `1` | 进入铁馆更衣室剧情 |
| `微醺小酒馆` / `2` | 进入微醺小酒馆剧情 |
| `男生宿舍熄灯后` / `3` | 进入男生宿舍剧情 |
| `退出场景` / `离开场景` / `退出` | 结束剧情并存盘离开 |

---

## ⚙️ 配置说明

在 `plugins/config.toml` 中配置：

```toml
[heartbeat_club]
enable = true
mode = 'blacklist'
limits = []
```
