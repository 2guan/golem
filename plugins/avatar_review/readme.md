# 好友头像锐评插件 (avatar_review)

调用多模态视觉大模型（Vision LLM），自动抓取群成员或私聊好友的微信高清头像，从构图、色调、艺术风格与精神状态等维度进行幽默毒舌、犀利深刻的“鉴赏打分”与专属改造建议。

---

## 📌 核心功能

1. **自动提取头像**：自动获取发送者、被 @ 成员或指定群友的高清微信头像链接。
2. **多模态视觉解析**：将头像传入 Vision 大模型进行画面分析，识别人物构图、动漫角色、自拍光线或抽象元素。
3. **犀利毒舌点评**：采用幽默风趣、松弛且情商在线的语言风格输出报告，包括：
   - 🎯 头像标签与第一印象
   - 📊 颜值/逼格/精神状态打分（0-100分）
   - 🔍 构图细节与深层心理剖析
   - 💡 专属下饭改造建议
4. **群聊与私聊全支持**：既可以在群内 @机器人 相互点评活跃气氛，也可私聊让机器人给出客观评价。

---

## 🎮 使用方法与触发词

| 指令 | 触发场景 | 说明 |
| :--- | :--- | :--- |
| `评测头像` / `锐评头像` | 群聊 / 私聊 | 对触发者本人的微信头像进行全面锐评打分 |
| `@机器人 锐评头像` | 群聊 | 在群里呼叫机器人点评自己 |
| `头像打分` / `测头像` / `看头像` | 群聊 / 私聊 | 同上，别名指令 |
| `头像帮助` / `头像评测帮助` | 群聊 / 私聊 | 查看插件用法说明 |

---

## ⚙️ 配置说明

在 `plugins/config.toml` 中配置（需要配置支持 Vision 的大模型接口）：

```toml
[avatar_review]
enable = true
mode = 'blacklist'
limits = []

[avatar_review.config]
base_url = 'https://token-plan-cn.xiaomimimo.com/v1'  # 兼容 OpenAI 的 Vision API 基础地址
api_key = 'your_api_key_here'                        # API Key
model = 'mimo-v2.6-flash'                            # 视觉模型名称（需支持图片输入）
```
