# AI 图像生成与自拍插件 (image_gen)

基于 Seedream 多模态生图大模型，为机器人注入强大的多模态视觉生成能力。支持根据自然语言提示词（Prompt）生成艺术插画、参考图垫图图生图，以及符合人设逼真写实的生活自拍照。

---

## 📌 核心功能

1. **写实生活自拍 (Selfie)**：
   - 识别用户想看自拍的意图或指定特定生活场景（如：“在故宫角楼拍张照”、“来张健身房的自拍”）。
   - 自动注入角色人设特征（如 36岁壮实程序员、短发、生活感自拍），输出真实自然的手机自拍照。
   - 具备与 `ai` 对话插件的双向联动能力，当对话大模型输出 `<image ref="selfie" .../>` 标签时自动异步拦截并生图发送。
2. **文本生图 (Text-to-Image)**：
   - 识别用户绘图指令（如：“画一只戴墨镜在沙滩上的小猫”），自动丰富提示词并调用 Seedream 图像模型生成超清大图。
3. **图生图与风格迁移 (Image-to-Image)**：
   - 自动关联引用消息中的图片，或会话中 5 分钟内最新发送的照片。
   - 用户发送“帮我画成赛博朋克风”、“改造成油画风格”时，自动提取原图作为参考图垫图重绘。
4. **微信原生多媒体投递**：
   - 优先通过底层微信 CDN 高清原图上传发送；在不同平台模式下均能稳定送达。

## 🎮 使用方法与触发词

### 1. 拟真自拍指令
- `自拍` / `来张自拍` / `发张自拍` / `看自拍`
- `在天安门拍张照`
- `来张在海边散步的自拍`
- `发一张在健身房大汗淋漓的自拍`

### 2. 文生图指令
- `生图 [画面描述]`
- `画图 [画面描述]`
- `画一个 [画面描述]` / `画一张 [画面描述]`
- `帮我画 [画面描述]`

### 3. 图生图指令
- 引用群内图片，回复：`帮我画成赛博朋克风格`
- 发送图片后紧接着发送：`改成宫崎骏动漫风格`

## ⚙️ 配置说明

在 `plugins/config.toml` 中配置：

```toml
[image_gen]
enable = true
mode = 'blacklist'
limits = []

[image_gen.config]
api_key = 'your_seedream_api_key'                     # Seedream API Key（留空则回退内置默认通道）
base_url = 'https://api.seedream.com/v1'              # API 基础端点
model = 'seedream-v3'                                 # 模型名称
width = 1024                                          # 默认出图宽度
height = 1024                                         # 默认出图高度
selfie_prompt_prefix = '真实生活质感手机前置自拍，自然光线' # 自拍基础风格前缀
```
