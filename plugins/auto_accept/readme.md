# 自动通过好友与欢迎语插件 (auto_accept)

自动处理微信新好友添加申请，自动验证通过并向新好友发送个性化欢迎语与功能指引，同时支持将加好友通知实时推送给机器人主人（Owner）。

---

## 📌 核心功能

1. **自动验证添加**：监听到微信好友验证消息（`message.TypeVerify`）后，自动提取凭证完成验证添加。
2. **好友防刷去重**：内置去重机制，防止微信系统重试或网络延迟导致重复回复。
3. **延迟拟人招呼**：支持配置通过后的延时发送时间（默认 2 秒），避免机械秒回。
4. **个性化欢迎语**：支持配置自定义欢迎文案；留空时自动发送富有亲和力的机器人人设指引。
5. **申请附言过滤**：支持关键词过滤，仅通过包含指定附言（如特定邀请码/暗号）的好友申请。
6. **主人实时通知**：添加新好友后，自动将对方昵称、微信号、申请来源与附言实时私聊汇报给所有者。

---

## ⚙️ 配置说明

在 `plugins/config.toml` 中配置：

```toml
[auto_accept]
enable = true
mode = 'blacklist'
limits = []

[auto_accept.config]
auto_verify = true             # 是否自动通过好友申请（true: 自动通过; false: 仅记录不通过）
greeting_enabled = true        # 通过后是否自动向新好友发送打招呼消息
greeting_delay_seconds = 2     # 通过后延迟发送打招呼消息的秒数（拟人化延时）
notify_owner = true            # 通过后是否向主人（Owner）私聊发送通知
keyword_filter = ''            # 好友申请附言关键词过滤（留空表示不限制；填入文本则只有附言包含该词才通过）
custom_greeting = ''           # 自定义欢迎语，留空则使用默认专属指引文案
```

---

## 💬 默认欢迎语样式

当 `custom_greeting` 为空时，通过好友后将自动发送：

> 嗨！我是你的智能伙伴，很高兴认识你！🎉
> 
> 我可以陪你日常闲聊、答疑解惑，还能支持各种群聊游戏与实用小工具。
> 随时给我发消息或者拉我进群一起玩吧~
