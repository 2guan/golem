# 无限冒险谭插件 (infinite_adventure)

开放式双男主文字 RPG：基于大模型实时演进的剧情互动系统。支持任意自定义主题脑洞或随机灵感盲盒开局，支持**私聊 1V1 深度沉浸剧情**与**群聊双人默契探索 / 兄弟小队共斗**。

---

## 📌 核心功能与玩法设计

1. **私聊 1V1 深度互动**：
   - 随心定义题材（现代悬疑、末世废土、修仙逆袭、科幻星际、都市奇幻等）。
   - 主角与搭档角色性格丰满、互相扶持。大模型根据玩家每一步的行动自由衍生新剧情。
2. **群聊小队共斗模式**：
   - 支持多位群友组建 2~4 人探险小队，由群友分别担任不同战术定位（前排坦度、输出核心、战术指挥、支援医疗）。
   - 小队成员共同面对随机遭遇战、解密关卡与命运抉择。
3. **动态状态机与行囊背包**：
   - 自动记录生命值（HP）、体力、状态效果（流血、兴奋、中毒等）与收集的道具装备。
4. **随机灵感盲盒**：
   - 没想好玩什么题材时，一键抽取预设高质量剧本盲盒立即开跑。

---

## 🎮 使用方法与触发词

### 私聊玩法
| 指令 | 说明 |
| :--- | :--- |
| `无限冒险` / `冒险帮助` | 查看玩法帮助说明 |
| `开启冒险 [自定义脑洞]` | 以指定脑洞开局（例如：`开启冒险 赛博朋克黑市潜入`） |
| `随机冒险` / `灵感盲盒` | 随机抽取预制世界观剧情即刻开跑 |
| `查看状态` / `背包` | 查看当前生命值、体力、角色状态与拾取道具 |
| `退出冒险` / `结束冒险` | 存盘离开当前剧情 |

### 群聊小队玩法
| 指令 | 说明 |
| :--- | :--- |
| `@某人 双人冒险 [脑洞]` | 邀请指定群友发起双人双男主探险 |
| `组建小队 [脑洞]` | 发起群内多人冒险集结（等待其他群友加入） |
| `加入小队` / `报名小队` | 其他群友响应集结加入队伍 |
| `小队开跑` / `开始小队` | 发起人确认全员到齐，正式开启小队剧本 |
| `小队状态` | 查看队伍全员生命值与背包物资 |
| `解散小队` / `结束小队` | 解散或提前终止当前小队冒险 |

## ⚙️ 配置说明

在 `plugins/config.toml` 中配置：

```toml
[infinite_adventure]
enable = true
mode = 'blacklist'
limits = []

[infinite_adventure.config]
save_file = 'data/infinite_adventure.json' # 存档文件持久化路径
max_solo_turns = 30                        # 私聊单轮推荐最大轮次
group_squad_max_members = 4                # 群聊小队最大允许人数
group_timeout_minutes = 20                 # 群聊无操作自动超时归档分钟数
```
