# 主动添加好友插件 (add_friend)

`add_friend` 是 Golem 的主动好友添加与频控插件。为保护微信账号安全、防止因频繁主动加人触发封禁，该插件内置了**每日主动添加上限配额**（默认每天最多 3 次，可自定义），并且支持搜索添加与群成员即时加好友。

---

## 一、主要特性

1. **每日上限频控与防封保护**：
   - 支持自定义 `daily_limit`（默认为 **3** 次/天）。
   - 自动跨天（次日 00:00）重置计数，防止主动加人超限被微信风控。
   - 申请失败自动回退额度，申请成功记录历史明细。
2. **多场景添加支持**：
   - **群内快捷添加**：群友在群内发送“加我好友”或“机器人加我”，机器人主动向该群友发送好友申请（Scene 14）。
   - **精确搜索添加**：主人发送 `#加好友 <微信号/手机号/wxid> [附言]`，后台自动发起搜索并递交好友申请（Scene 15）。
3. **额度管理与查询**：
   - 支持实时查询今日加好友额度与已用记录。
   - 仅主人拥有额度重置权限（`#加好友重置`）。

---

## 二、使用指令

| 指令 | 适用场景 | 权限 | 说明 |
| :--- | :--- | :--- | :--- |
| `加我好友` / `机器人加我` | 群聊 | 全体成员（或仅主人） | 机器人在群里直接向发送者发起好友申请 |
| `#加好友 <账号> [附言]` | 私聊 / 群聊 | 主人（或放开） | 精确搜索微信号/手机号/wxid并发送添加好友申请 |
| `#加好友统计` / `#加好友额度` | 私聊 / 群聊 | 所有人 | 查看今日配额上限、已用次数、剩余额度及申请明细 |
| `#加好友重置` | 私聊 / 群聊 | 仅机器人主人 | 强制清空今日使用计数，恢复满额度 |

---

## 三、配置说明

在 `plugins/config.toml` 中配置：

```toml
# add_friend 插件：主动添加微信好友插件（带每日上限频控保护）
[add_friend]
enable = true
limits = []
mode = 'blacklist'

[add_friend.config]
daily_limit = 3              # 每天主动添加好友的最大上限（默认 3 次）
default_greeting = "你好，我是{bot_name}"  # 默认申请附言（自动替换为机器人微信昵称）
owner_only = false           # 为 true 时仅允许主人主动加人；为 false 时群友发送“加我好友”也可触发
data_file = "data/add_friend_stats.json"  # 额度与明细数据持久化文件
```

---

## 四、安全建议

- 微信对主动添加好友（尤其是全网搜索微信号/手机号）有严格的风控算法，建议保持默认每日上限 **3~5** 次以内。
- 若需大批量通过好友，建议使用被动添加模式的 [`auto_accept`](../auto_accept/readme.md) 插件。
