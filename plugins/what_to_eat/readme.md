# 今天吃什么美食盲盒插件 (what_to_eat)

专为干饭人打造的美食灵感决策助手：解决“今天吃什么”的人生终极难题。具备精准时段感知、正负向口味偏好过滤、快速换菜以及复杂饮食诉求 AI 私房定制。

---

## 📌 核心功能

1. **时段感知与科学推荐**：
   - 自动识别当前时间段：早餐（06:00-10:00）、午餐（11:00-14:00）、下午茶（14:00-17:00）、晚餐（17:00-21:00）、夜宵（21:00-04:00）。
   - 按对应餐段的经典菜系与小吃特征进行搭配推荐。
2. **正负向偏好双向过滤**：
   - **正向口味指引**：支持 `吃什么 减脂`、`吃什么 清淡`、`吃什么 爆辣`、`吃什么 面食`。
   - **负向避雷排除**：支持 `不想吃面`、`不吃辣`、`不想喝奶茶`，后厨自动剔除雷区。
3. **快速换菜机制**：
   - 推荐的美食不合心意时，发送 `换一个`，系统自动规避本轮已推荐菜品，无缝换一道好菜。
4. **AI 私房定制引擎**：
   - 当检测到复杂饮食背景（如“预算20块”、“胃难受想喝粥”、“生病发烧”、“减脂期聚餐”等），自动调用大模型生成专属定制食谱与营养搭配建议。

---

## 🎮 使用方法与触发词

| 指令 | 说明 |
| :--- | :--- |
| `今天吃什么` / `吃什么` | 自动感知当前餐段推荐一道美食与搭配饮品/小吃 |
| `中午吃什么` / `晚上吃什么` / `夜宵吃什么` | 指定餐段推荐 |
| `换一个` / `换道菜` / `再换一个` | 对推荐不满意，随时换一道新菜 |
| `吃什么 减脂` / `吃什么 清淡` / `吃什么 爆辣` | 按指定口味偏好挑选 |
| `不想吃面` / `不吃辣` / `不想喝甜的` | 排除特定类别与口感 |
| `吃什么 胃疼` / `吃什么 预算20` | 触发 AI 私房定制，量身定制方案 |
| `吃什么帮助` / `美食帮助` | 查看本插件使用说明 |

---

## ⚙️ 配置说明

在 `plugins/config.toml` 中配置：

```toml
[what_to_eat]
enable = true
mode = 'blacklist'
limits = []

[what_to_eat.config]
enable_ai = true  # 当识别到复杂自定义诉求时，是否调用 AI 大模型进行私房定制
```
